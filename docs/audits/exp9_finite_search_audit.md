# exp9有限搜索嵌套验证核查

结论：当前源代码的内外层被试隔离、训练折内筛选、内层选择配置及外层最终评估的主干正确。存在单位敏感的常数过滤、协议表述与随机状态差异，以及总结中的指标与推断问题。

## 实际流程

1. 读取人体成分50、阻抗61、纹理1422列，合计1533列。排除编号/手指元数据；标签固定为PT>156。按固定被试分折清单做外层5折。
2. 外层0、1分别训练25人，测试7人；外层2、3、4分别训练26人，测试6人。
3. 在每个外层训练被试集合内部做5折：25人时每折20训练/5验证；26人时20训练/6验证或21训练/5验证。
4. 每个内层训练折独立进行常数过滤、Spearman或浅RF粗筛、模态内配额去冗余、跨模态去冗余。
5. RFE基模型为100棵浅RF、depth5、leaf2；step1删到1个，再以ranking<=k获得3/5/6/8/11/15个特征子集。该方法是逐步删除，不是枚举所有特征组合。
6. 每个内层验证折评估2路线×6特征数×4参数=48种配置；最终分类森林为400棵，depth5或8、leaf2或4、sqrt、种子42，分类阈值0.5。
7. 合并仅覆盖外层训练被试的内层折外预测；以准确率、AUC、较少特征及较浅树等固定次序择优。
8. 全部外层训练被试重新执行选定粗筛路线和RFE，再拟合分类器、预测外层测试被试。同折拟合性别、性别+身高、训练多数类基线。

代码位置：exp9_nested_cv_finite_search.py的208–259、297–425行。

- 原始特征表与标签表的被试/手指按行对齐；当前数据没有缺失值，性别列与标签表一致。
- 保存预测覆盖128条记录、32人，无缺失，每人仅一个外层测试折。
- 全部5个外层所选配置重跑筛选、RFE、最终拟合；特征名单和预测类别完全一致，概率最大差2.23e-16以内。
- 全部25个内层折的所选配置重跑，内层OOF准确率与AUC均与审计文件一致。没有重新训练所有240个外层-候选配置，但保存的每折48条记录均核对了选择规则和所选最大项。
- 在真实外层0训练数据上，删到1再取ranking<=6与直接停止在6的RFE结果一致。
- 内层回放明细保存为exp9_selected_inner_replay.json。

## 应修正的筛选规则

screen_and_dedup_pool的107行使用ptp>1e-8识别非恒定变量。这是绝对幅度阈值，并不等价于常数过滤。

在每个外层训练集上，45个具有真实变化的纹理特征因此被排除。例如Tex::BP_wt_norm_moments_14__79在外层0训练集的范围是[-2.5056e-9,-1.6677e-10]，跨度2.3388e-9，虽非恒定仍被删。仅将同一列乘以1e9，就会由删除变为保留。

应改为真正的恒定值判断，或在训练折拟合尺度处理后采用有解释的相对阈值。原始尺度的RF数值精度也应在修正后对照核查。该问题可能改变筛选结果，但尚未通过修正对照实验证明它造成44.53%的准确率。

## 其他实现与记录问题

- 64–66行在加载阶段直接coerce并填0，并非总结中所述的折内缺失处理。固定填0本身没有利用测试统计量；当前没有缺失，未发现这一点改变本次成绩。仍建议遇到非法值报错，若采用学习型填补则在训练折拟合。
- 内层粗筛随机状态为100+50×outer_f+inner_id，RFE再加10；外层粗筛为42+outer_f，RFE再加10。最终分类器均42。不同随机实现不构成测试泄漏，但增加筛选差异，不能笼统写全流程固定42。
- 未保存每个内层折的完整特征名单、预测、数据/代码哈希。现有审计文件保存的是候选配置汇总与外层最终特征。回放核验不能代替今后的原始留档。

## 结果与总结错误

逐条预测核算：多模态57/128=44.53125%，性别80/128=62.5%，性别+身高76/128=59.375%，多数类46/128=35.9375%。多模态混淆矩阵[[30,34],[37,27]]，AUC0.47509765625。

总结中的性别F1=60.32%及多数类F1=0%与保存预测不符。二分类正类F1分别为61.29%和41.43%；Macro F1则为62.46%和35.37%，需注明口径。汇总JSON未计算多数类pooled AUC，不能无依据填入0.5；折内常数预测的AUC与跨折合并指标不是同一量。

44.53%描述的是此筛选/模型规则在此被试划分下的内部验证，不是数据的可预测性上限；未进行相应推断就不应写显著、证实混杂主导或证明高维过拟合因果。方法开发已经反复查看同一队列，也不能声称独立外部验证。
